## 2. Seis celdas de tabla

Estas no las puedo tocar por API. El reemplazo de texto de Google Docs busca por substring, y una celda que contiene solamente `8` o `45` no se puede identificar sin pisar todos los demás «8» y «45» del documento. Los porcentajes y los puntajes promedio de esas mismas tablas **sí** quedaron corregidos; lo único pendiente son los conteos.

### Tabla 10 — Distribución por etapa

| Celda | Dice | Debe decir |
|---|---|---|
| ANÁLISIS → N | 8 | **7** |
| ANÁLISIS → % | 11,0% | **10,4%** |
| DELEGACIÓN → N | 45 | **40** |
| PERSPECTIVA → % | 27,4% | **29,9%** |
| Total → N | 73 | **67** |

### Tabla 12 — Directivo no-fundador

| Celda | Dice | Debe decir |
|---|---|---|
| Sí → N | 44 | **40** |
| No → N | 29 | **27** |
